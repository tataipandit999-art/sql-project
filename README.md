# CineBook – Movie Ticket Booking System

CineBook is a **MySQL-based Database Management System project** designed to manage and analyze movie ticket booking activities. It stores customer, movie, theatre, show, booking, payment, cancellation, and refund information.

## Features
- Customer and Movie Management
- Theatre and Screen Management
- Show and Booking Records
- Payment and Refund Tracking
- Booking Cancellation Analysis
- Revenue and Customer Spending Analysis
- Multi-table JOIN Operations
- Database Views and Indexing

## Database Tables
The project contains 9 related tables:
1. Customers
2. Movies
3. Theatres
4. Screens
5. Shows
6. Bookings
7. Payments
8. Booking_Cancellations
9. Payment_Refunds

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- Aggregate Functions (COUNT, SUM, AVG, MIN, MAX)
- GROUP BY and HAVING
- INNER JOIN and Multi-table JOINs
- Subqueries
- Window Functions
- Indexes
- Database Views

## Technologies Used
- MySQL
- SQL
- MySQL Workbench
- VS Code
- Microsoft Excel

## Dataset
The project uses movie ticket booking data covering **January 2026 – June 2026**.

## How to Run
1. Open MySQL Workbench.
2. Execute `01_database.sql` to create the database.
3. Execute `02_create_tables.sql` to create all tables.
4. Execute `03_insert_data.sql` to insert the records.
5. Run the SQL queries to explore and analyze the database.
